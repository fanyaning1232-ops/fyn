# 小红书一键排版工具（本地版）

这是一个**本地离线运行**的轻量工具：

- 输入：一段原始文案（可直接传参或从文件读取）
- 输出：自动分段、加小标题、带 emoji 与话题标签的可发布文案

适合快速整理小红书笔记草稿，减少手动排版时间。

## 1. 环境准备

建议 Python 3.9+。

```bash
python -m venv .venv
source .venv/bin/activate
pip install -U pip
pip install -r requirements.txt
```

> 当前工具仅使用 Python 标准库，`requirements.txt` 为空依赖。

## 2. 快速开始

### 方式 A：直接传入文本

```bash
python app.py \
  --text "早起后皮肤状态很差，我最近做了3件小事。第一是提前半小时睡觉，第二是早上温水洗脸，第三是出门前固定防晒。坚持两周后气色明显更稳定。" \
  --title "7天改善晨起状态的小习惯" \
  --emoji-style soft \
  --hashtags "护肤 早起习惯"
```

### 方式 B：从文件读取并输出到文件

```bash
python app.py \
  --input draft.txt \
  --output out/post.txt \
  --title "通勤穿搭复盘" \
  --emoji-style clean \
  --hashtags "通勤穿搭 职场女生"
```

## 3. 参数说明

- `--text`：直接传入原始文案
- `--input`：从文本文件读取原始文案
- `--output`：输出文件路径；不填则打印到终端
- `--title`：可选标题（置顶显示）
- `--emoji-style`：emoji 风格，可选：
  - `soft`：温柔风（默认）
  - `cute`：可爱风
  - `clean`：简洁风
  - `none`：不加 emoji
- `--hashtags`：追加话题标签，空格分隔
- `--cta`：结尾互动引导文案

## 4. 排版规则（默认）

1. 清理多余空白与空行。
2. 按句号/问号/感叹号自动切分句子。
3. 自动分为 3 段：
   - 先说重点
   - 展开聊聊
   - 实操建议
4. 每段变成项目符号列表。
5. 自动添加默认话题：`#小红书文案 #一键排版 #内容创作`。

## 5. 示例输出

```text
✨ 7天改善晨起状态的小习惯 ✨

✨ 先说重点
- 早起后皮肤状态很差，
- 我最近做了3件小事。

- 第二是早上温水洗脸，
- 第三是出门前固定防晒。

📝 实操建议

#小红书文案 #一键排版 #内容创作 #护肤 #早起习惯
```
