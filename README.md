# 小红书一键排版工具（网页版）

这是一个纯前端（HTML/CSS/JavaScript）的本地网页工具：

- 输入：原始文案草稿
- 输出：自动分段、加小标题、带 emoji 与话题标签的可发布内容

## 功能

- 自动清理多余空白与空行
- 按中文标点切分句子
- 自动分为 3 段（先说重点 / 展开聊聊 / 实操建议）
- 转为项目符号格式
- 可选 emoji 风格（soft/cute/clean/none）
- 自动追加默认标签与自定义标签
- 一键复制结果

## 使用方式

1. 直接用浏览器打开 `index.html`。
2. 填写标题（可选）和原始文案。
3. 选择 emoji 风格，补充标签与互动引导。
4. 点击「一键排版」。
5. 点击「复制结果」粘贴到小红书。

> 无需 Python、无需安装依赖、离线可用。

## 文件说明

- `index.html`：页面结构
- `styles.css`：页面样式
- `script.js`：排版逻辑与交互
